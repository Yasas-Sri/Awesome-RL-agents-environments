# Contributing

Open a pull request that adds one entry per line, in the matching section:

```
- [Name](https://link) - Short description ending with a period.
```

- The project must be an RL environment, benchmark, environment framework, or closely related tooling.
- It should be public and reasonably maintained.
- Keep descriptions short and neutral (no marketing).
- Check for duplicates before adding.
- New section? Add it to the Contents list too.
